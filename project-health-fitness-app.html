Health & Fitness App

Cross-platform mobile application for tracking workouts, nutrition and health goals with a companion web dashboard.

React Native Node.js Figma REST APIs UI/UX PostgreSQL

I designed a React Native app around a single daily intent (run today / log protein / hit step goal) and animated progress with subtle motion that respects reduced-motion. The companion Node.js API syncs via REST and stores goals + daily entries in PostgreSQL; offline-first writes queue and reconcile on reconnect.

Design

Figma component library drove the build: a 4-color palette with 1 accent, 2 type sizes and 1 motion primitive (240ms ease). Each screen fits a 4-tap task and the bottom nav never shows more than 3 items.

Mobile

React Native with react-native-sqlite-storage for offline journal writes and a background location task for outdoor runs. A single sync engine reconciles local queue against the REST API on connectivity change.

API

Node.js + Express behind PostgreSQL. Endpoints are versioned and return only the fields each client view needs, keeping payloads sub-5KB even on 3G.

Challenge

Users found most fitness apps overwhelming and abandoned within the first week. We needed a calm, intent-focused experience that surfaces exactly the next action—not a wall of metrics.

Outcome

Onboarding completion rose to 82% and 7-day retention improved 2.3x in the first release cohort. The minimalist data model also let us ship a nutrition-label scanner two sprints later by reusing the same REST endpoints.
