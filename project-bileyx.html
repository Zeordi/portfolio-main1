Web Application Role: Frontend Developer Tech: Vue.js, Tailwind CSS, REST APIs, SCSS, UI/UX

Bileyx

Event management and ticketing platform for creating, promoting and selling tickets to events.

Vue.js Tailwind CSS REST APIs SCSS UI/UX

I built the buyer and organizer UIs in Vue 3 with Vite and Tailwind, consuming a REST API for event data, inventory and orders. Tickets are rendered as QR codes (on the client, via a canvas encoder) that venues scan with a companion check-in app. Inventory locks optimistically and is released if payment does not complete within 5 minutes.

Event Builder

Organizers fill a schema-driven form (title, dates, venue, ticket tiers, cover image) and get a live preview. The form state is saved as a draft in localStorage so a browser crash never loses progress.

Checkout

Stripe Payment Element handles cards and mobile money. After payment we create the order, issue the ticket record, and email a PDF + a high-DPI QR PNG. The QR encodes a signed ticket id, not PII.

Check-in App

A small Vue PWA used at the door. It scans the QR with the device camera, calls the API to mark the ticket used, and plays a soft beep. Works offline for 2 hours by caching recent ticket hashes.

Challenge

Event organizers needed a fast way to launch ticketed events without developers, while buyers wanted one click from discovering an event to receiving a scannable QR ticket—on any device.

Outcome

The platform processed 12,000+ tickets across 400+ events in its first year. Check-in scans take under 2 seconds per attendee, and the QR flow replaced the previous PDF-email flow that had a 5% no-entry rate.
