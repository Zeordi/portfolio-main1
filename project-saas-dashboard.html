Web Application Role: Full-Stack Developer Tech: Vue.js, Django, Pinecone, REST APIs, Chart.js, PostgreSQL

SaaS Dashboard

A Django admin dashboard for an API-as-a-service product, with charts, usage billing and team management.

Vue.js Django Pinecone REST APIs Chart.js PostgreSQL

I added a Vue 3 single-page admin on top of the existing Django REST API, backed by PostgreSQL. Key endpoints: a usage-aggregation cron exposed as a meter, a Stripe-billing webhook consumer, and a team-membership model with role-based permissions. Charts use Chart.js fed by the same metrics API customers query.

Usage Metering

Every API request is appended to a time-series table. A nightly job rolls up per-org, per-plan usage which the dashboard and the public billing API both read, so customers see the same numbers internally and via the API.

Team & Roles

Organizations have owners, admins and read-only members. The JWT issued at login encodes the membership set, and Django REST Framework viewsets gate field-level access so a member can never list another org's resources.

Billing

Stripe Checkout creates the subscription; webhooks for invoice.created / invoice.payment_succeeded update our own Invoice model. Downgrade is immediate, upgrade is prorated via subscription items.

Challenge

Our API customers needed a self-service portal to monitor usage, manage billing and collaborate in teams, but our existing docs-only onboarding left them guessing at limits.

Outcome

Self-service adoption doubled and support tickets about billing dropped to near zero. Revenue recognition is now automated via the Stripe webhook consumer, with invoices reconciled nightly.
